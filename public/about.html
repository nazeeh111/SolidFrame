SolidFrame

A browser CAD workspace for sketching, solid modeling, and editable engineering projects.

Built on open engineering

SolidFrame is an independently adapted derivative of Chili3D, created by 仙阁 (Xiange Chen) and its contributors. The original modeling engine, document system, geometric operations, and plugin architecture remain the foundation of this application. The SolidFrame interface, editable fixture example, startup safeguards, and deployment improvements are adaptations by nazeeh111.

Your files

Save stores documents in this browser's local database. Download a .cd document to keep an editable backup. Clearing site data, using private browsing, or changing browsers can remove or separate locally saved projects. Export STEP, IGES, BREP, STL, OBJ, or PLY for other tools; these formats do not retain the complete native editing history.

Plugins and optional services

Modeling uses the local WebAssembly geometry engine. The adapted app does not load tracking scripts or promotional feeds. Link parameters never authorize plugin execution. Only import plugin files whose code you trust. Optional AI tools require your separately configured provider; they are not needed for CAD modeling and have not been configured by this project.
