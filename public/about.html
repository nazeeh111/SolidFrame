SolidFrame

A browser CAD workspace for sketching, solid modeling, and editable engineering projects.

Developed by Nazeeh Abdul-Hadi

Nazeeh develops and maintains SolidFrame, including its project hub, workspace design, editable fixture, keyboard-accessible modeling controls, startup safeguards, and deployment improvements.

Your files

Save stores documents in this browser's local database. Download a .cd document to keep an editable backup. Clearing site data, using private browsing, or changing browsers can remove or separate locally saved projects. Export STEP, IGES, BREP, STL, OBJ, or PLY for other tools; these formats do not retain the complete native editing history.

Plugins and optional services

Modeling uses the local WebAssembly geometry engine. SolidFrame does not load tracking scripts or promotional feeds. Link parameters never authorize plugin execution. Only import plugin files whose code you trust. Optional AI tools require your separately configured provider; they are not needed for CAD modeling and have not been configured by this project.
